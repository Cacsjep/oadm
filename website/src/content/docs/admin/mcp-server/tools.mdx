These are the tools an agent can be offered. It sees only the ones the role of its access key allows, of the plugins that are on.
A change is always two tools: the preview checks everything and changes nothing, the run takes only the preview's handle
and runs after the user agreed.

## Server

| Tool | Kind | What it does |
| --- | --- | --- |
| `oadm_server_info` | Read | The OADM server, who you are, your role and what it allows, the limits of this server and how many devices you see. Call it first. |
| `oadm_server_status` | Read | OADM's own state: OADM PRO, which plugins are on, MCP and the assistant, and the date of the list of Axis vulnerabilities. Read only. |
| `oadm_settings_get` | Read | The server settings OADM shows every user: how it scans, retries, runs tasks and checks clocks. Administrators change them with oadm_settings_set_preview. |
| `oadm_settings_set_preview` | Preview | Shows the old and new value of each server setting you name, checked as the Settings page checks them; nothing is changed. Then call oadm_settings_set_run with the handle. |
| `oadm_settings_set_run` | Run (changes) | Saves the settings of a preview, checked again, as Save on the Settings page does; audited as server settings. |

| `oadm_devices_summary` | Read | Counts of your devices by status, model, AXIS OS, site, tag, category, chip, clock, NTP, certificate, vulnerabilities or CVE, and what needs a look (clocks, certificates, CVEs). Call it first: OADM already knows this without asking the devices. |

| `oadm_tasks_catalog` | Read | The tasks you may run on the devices of a filter: per task how many can run it, why the others cannot, and its input schema. Call it before oadm_task_preview. |
| `oadm_tasks_delete_all_preview` | Preview | Shows how many tasks the history holds; nothing is deleted. Then call oadm_tasks_delete_all_run with the handle. |
| `oadm_tasks_delete_all_run` | Run (changes) | Cancels every waiting and running task, then deletes the whole task history. |
| `oadm_tasks_delete_preview` | Preview | Shows which tasks of a run or of a list of ids would leave the task history; nothing is deleted. Then call oadm_tasks_delete_run with the handle. |
| `oadm_tasks_delete_run` | Run (changes) | Deletes the tasks of a preview from the history with their steps and logs. A waiting or running task is cancelled first. |
| `oadm_tasks_get` | Read | One task with its steps and its log (the newest 200 lines). Take the id from oadm_tasks_list. |
| `oadm_tasks_list` | Read | Tasks of your devices from OADM's task history, the newest first, with the counts per state first. Pass batch to follow the tasks of one run; next_cursor for the next page. |
| `oadm_tasks_summary` | Read | OADM's task history of your devices summed up: counts per state and groups by result, task, plugin, owner, device or day, the largest first. Pass status Failed to group the failures by their error. |
