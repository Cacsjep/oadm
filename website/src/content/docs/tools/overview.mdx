---
title: Plugins
description: Every plugin that comes with OADM.
---

Each plugin has its own page in OADM, grouped like in the navigation rail. Administrators turn plugins on or off on the
[Plugins page](../../admin/plugins/).

| Group | Plugin | What it does | Default |
|---|---|---|---|
| Servers | [NTP server](../ntp-server/) | Serves the time to your devices. | On |
| | [DHCP server](../dhcp-server/) | Gives addresses to your devices and adds new Axis devices automatically. | On |
| Automation | [VAPIX Commander](../vapix-commander/) | Sends VAPIX commands to one device or rolls them out to many. | On |
| | [Device triggers](../device-triggers/) | Any event of your devices in event rules. | Off |
| | [Action Rule Editor](../action-rule-editor/) | The cameras' own action rules, changed on many cameras at once. | Off |
| Security | [PKI](../pki/) | Certificates for HTTPS and IEEE 802.1X on your devices, and the rules for them. | Always on |
| | [802.1X server](../radius-server/) | Your switches let only the devices OADM manages onto the network (OADM PRO, a tab of PKI). | Off |
| | [EST server](../est-server/) | Cameras get and renew their certificates by themselves (OADM PRO, a tab of PKI). | Off |
| | [Hardening scan](../hardening-scan/) | Checks your devices against the AXIS OS hardening guide. | Off |
| Monitoring | [Live View](../live-view/) | Several cameras at once, in saved views. | Off |
| | [Dashboards](../dashboards/) | Live values of your device triggers and live video, in saved dashboards. | Off |
| | [Metadata Monitor](../metadata-monitor/) | The events a camera sends, live. | Off |
| | [Image Health Dashboard](../image-health-dashboard/) | The AXIS Image Health Analytics status of your cameras. | Off |
| | [I/O Monitor](../io-monitor/) | The inputs and outputs of a device, live. | Off |
| | [Load test](../load-test/) | Whether your network and cameras carry the load of all streams at once. | Off |
| Reporting | [Snapshot report](../snapshot-report/) | A current picture of your cameras and a PDF maintenance report. | Off |
| | [System report](../system-report/) | The system reports of many devices in one ZIP file for Axis support. | Always on |
| Maintenance | [Applications](../applications/) | The applications of many devices: versions, licenses, start, stop, install, remove. | Off |
| | [Edge Recording Export](../edge-recording-export/) | Downloads the recordings on your cameras' SD cards. | Off |
| | [Edge storage](../edge-storage/) | The SD cards of your cameras: check, format, encrypt, retention. | Off |
| Utilities | [Web View](../web-view/) | The web interface of your devices in tabs, already logged in. | On |

The everyday device work (restart, firmware, date and time, users, network settings and more) is in the device context
menu: see [Device tasks](../../tasks/overview/).

Want your own? See the [developer guide](../../dev/overview/).
