## The last 20 reads

The table below the video keeps the last 20 reads of the reader, newest on top. Drag the bar between video and table up for
a longer table.

<Image src={lastReads} alt="The page with the bar dragged up: a small video above a long table of reads with their cut-outs" class="screen" />

- A read is a new value in an area. The same text in every picture is one row, and an area without a value adds none.
- A watching reader fills the table also while the page is closed.
- While you change a reader without saving, the table shows what that draft read.
- On the video an area with a format shows one box, on its value, and none without a match.

### Cut-outs

Click a cut-out to see it larger and judge how well the characters show.

<Image src={cutOut} alt="The Cut-out dialog with the text AT-4020-12 upright, its area and its time" class="screen fit" />

Only users with **Live view** see cut-outs.

The table and its cut-outs stay in the server's memory, never on disk. They are gone when the server restarts, when you delete
the reader and when the plugin turns off.

## Pause to tune a format

On a belt the text is gone before you can adjust anything. Pause stops the page on the picture OADM read last, with its
areas and boxes.

<Image src={paused} alt="The page paused: the held picture, the table as it was, and each area's result above Save" class="screen" />

<Steps>

1. Press Pause in the bottom left corner of the picture.
2. Check the last 20 reads and open their cut-outs. The table stays as it is.
3. Change a format, or move, resize or add an area. OADM reads the same picture again.
4. Read the result above **Save**, such as `Area 1: DE-1011-22` or `Area 1: no match`.
5. Press Resume. The table comes up to date.

</Steps>

**Use read text as format** and **Save** work while paused.

<Aside>
Pause is only for this page. Saved readers keep reading and rules keep firing. Pause needs the **Live view** permission.
</Aside>

### Notes above Save

The chip above **Save** says what needs attention. While paused it shows that picture's alerts and each area's result.

## Belts and passing vehicles

Turn on **Moving objects** in the settings of a watching reader. Without it a text on a belt can be gone before the pictures
agree, and two labels can mix.

| | Off | **Moving objects** on |
|---|---|---|
| A value counts | When the last 5 pictures, compared, give the same value in 2 pictures in a row | When it was read the same in 2 pictures in a row |
| Good for | A sign or a meter that stays | A belt or a vehicle that passes |
| A misread in one picture | Changes nothing | Is ignored |

At 1 frame per second 2 pictures take 2 seconds, so a fast belt needs a higher rate.
