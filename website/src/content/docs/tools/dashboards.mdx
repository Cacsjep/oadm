Dashboards show live values of your devices: a temperature, a count, the last number plate, a gate that is open or
closed. A dashboard is a grid of widgets, each showing one value of one device, next to live video if you want it.
The values come from [Device triggers](../device-triggers/) and from OADM's own events, such as Device unreachable.

<Image src={page} alt="The dashboard Building A: two temperatures, a gate as an open lock, the last number plate and a camera" class="screen" />

## Open a dashboard

1. Dashboards is off when OADM is installed: an administrator turns it on under **Plugins**. Turn on
   **Device triggers** too and create a trigger for the event whose values you want to see.
2. Open **Dashboards** in the navigation rail.
3. Click a dashboard under **Dashboards**. It opens in a tab; open more and switch between the tabs.

A value that may be old is dimmed, with the reason below it: **Connection lost**, **Unreachable**. Point at a value to
see when it arrived.

## Create or change a dashboard

<Image src={edit} alt="A dashboard in edit mode: a frame around each widget and the settings of the selected widget on the right" class="screen" />

1. Click the + next to **Dashboards**, or the pen next to a dashboard. The bin next to it deletes the dashboard.
2. Drag an event from **Events** onto the grid, or click it. **Events** lists the values OADM has seen; when an event
   shows "Trigger the event once on the device.", make it happen once on the device and its values appear.
3. On the right, choose the **Device**, the **Value** and the **Widget**:
   - **On / Off**: an icon, a color and an optional text for each state.
   - **Text**: the value as the device sends it.
   - **Number**: decimal places, a unit, and thresholds that color the number from a value on (for example 25 orange,
     28 red).
   **Type** reads a value as a number, as yes / no or as text when the automatic choice does not fit. Clear **Show name**
   to give the value the whole widget.
   The copy icon next to a widget's X (or **Copy for other devices** in its settings) makes the same widget for each device you choose, for example input 1 on 20 I/O modules:
   each copy gets its device and its address in the name, in the next free place.
4. Drag a camera from **Cameras** onto the grid for live video. Choose its channel with the buttons on the picture.
5. Drag a widget to move it, drag one of its edges or corners to resize it, and click its X to remove it. Click a widget
   to change its settings. Sizes of icons and text are a share of the widget, so they grow with it.
6. Enter a name and click **Save**. **Cancel** throws your changes away.

A dashboard holds up to 50 widgets, of them up to 16 live videos.

## Good to know

- Dashboards are stored on the OADM server and shared by every user. When someone else saves a dashboard you have open,
  your tab follows.
- Who may create, change and delete dashboards is the right **Change dashboards** on the Users page. Viewers only open
  dashboards. Seeing video needs **Live view**.
- OADM keeps the values in memory only. After a server restart, on / off values come back at once; other values show
  **No value yet** until the device sends the event again.
- A device that was removed from OADM keeps its widget and says so.
