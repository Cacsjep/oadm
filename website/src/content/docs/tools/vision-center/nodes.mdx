Each node takes one kind of input and gives one kind of output. The node list offers only the nodes that fit.

| Kind | Carries |
|---|---|
| Picture | The camera's picture |
| Objects | Boxes with class and score. After a Track node each object also keeps an id |
| Crossings | Objects that crossed a line, with In or Out |
| Number | A live value |
| Yes or no | A condition |
| Pulse | A Timer's tick, only into **Reset**, **Send now** or a Throttle |

A pipeline has at most 32 nodes, and at most 2 model nodes (Detect objects, Classify) one after the other. Every node has
a **Name**, unique in the pipeline: rules and dashboards show it.

## Camera

The start of every pipeline, one per pipeline. **Stream** opens the stream settings: video source, resolution and frames
per second.

Live line: the camera and its stream, `AXIS Q1798-LE · 1280x720 @ 8 fps`.

## Models

### Detect objects

Takes a picture, gives objects.

| Setting | Values |
|---|---|
| **Model** | A detection model. Below it the model's class list |
| **Minimum score** | 1 to 99 %, default 50 % |
| **Classes** | **Every class** or the classes you choose |

At most 300 objects per picture, the surest first. Live line: `5 objects · 18 ms`.

Example: a model of COCO with **Classes** `person` finds only people.

### Classify

Takes a picture or objects, gives the same with a class added.

| Setting | Values |
|---|---|
| **Model** | A classification model |
| **Area** | Only on a picture, optional: classify only the part inside a drawn area. None: the whole picture |

On objects it classifies each box with a little margin, at most 16 per picture. Tracked objects are classified once and
again every 2 seconds. Live line: `3 objects · 18 ms`, on a picture `blue 87 % · 18 ms`.

Example: Detect objects (person) > Track > Classify with a helmet model > Filter **Class of Classify** `no helmet`.

## Objects

### Filter

Takes objects, keeps the ones that pass all its checks.

| Setting | Values |
|---|---|
| **Classes** | Optional: only these classes |
| **Minimum score** | 1 to 99 %, default 50 % |
| **Minimum size**, **Maximum size** | Optional, 0 to 100 % of the picture's height |
| **Class of Classify** | Optional: the class a Classify node before it gave. Upper and lower case do not matter |

Live line: `3 objects`. Example: **Minimum size** 10 % leaves out people far away.

### Track

Takes objects, gives tracked objects: each one keeps an id while it moves. Works only while **Watching**.

| Setting | Values |
|---|---|
| **Confirm after** | 1 to 30 pictures in a row, default 3. An object gets its id only then, so a flicker gets none |
| **Keep lost objects** | 0 to 30 s, default 1 s. An object hidden for a moment keeps its id |

Live line: `3 tracked`. Line, Dwell, Stationary and Direction need a Track node before them.

Only detections of 50 % or more start a track. With a **Minimum score** below 50 % such objects are never tracked.

### Dwell

Takes tracked objects after an Area, keeps the ones inside the area longer than **Longer than** (1 to 3,600 s, default
30 s). Works only while **Watching**. Live line: `2 objects`.

Example: people who wait at a counter longer than 2 minutes.

### Stationary

Takes tracked objects, keeps the ones that stayed in one place. Works only while **Watching**.

| Setting | Values |
|---|---|
| **Still for** | 5 to 3,600 s, default 60 s |
| **Movement allowed** | 1 to 20 % of the picture, default 3 %. A larger move starts the time again |

Live line: `2 objects`. Example: a vehicle that stopped in a fire lane.

### Direction

Takes tracked objects, keeps the ones moving along an arrow you draw on the video. Works only while **Watching**.

| Setting | Values |
|---|---|
| **Direction** | The arrow, drawn on the video |
| **Tolerance** | 10 to 90°, default 45° |
| **Minimum movement** | 1 to 50 % of the picture's height within the last second, default 5 % |

Live line: `2 objects`. Example: people walking the wrong way through an exit.

## Geometry

### Area

Takes objects, keeps the ones inside an area drawn on the video (3 to 16 points).

| Setting | Values |
|---|---|
| **Area** | Drawn on the video |
| **Inside by** | **Bottom centre** (default: feet, wheels), **Centre** or **Any overlap** |

With tracked objects it also counts how long each one has been inside. Live line: `2 inside`.

### Line

Takes tracked objects, gives crossings. Works only while **Watching**.

| Setting | Values |
|---|---|
| **Line** | Drawn on the video, with the In arrow |
| **Count** | **In and Out** (default), **In only** or **Out only** |

An object crosses when the bottom centre of its box passes the line. It never counts the same direction twice in a row.
Live line: `In 12 · Out 7`.

## Logic

### Compare

Takes a number, gives yes while it meets the condition.

| Setting | Values |
|---|---|
| **Condition** | **Greater than** (default), **At least**, **Equal to**, **At most**, **Less than** or **Between** |
| **Value** | Default 10 |
| **And** | Only for **Between**, default 20. Both ends count |

Live line: `14 > 10 · Yes`, `2 ≤ 4 ≤ 6 · Yes`. Example: yes while more than 20 people are in the lobby.

### And / Or

Takes yes or no and a **Second** one, gives **Both (and)** (default) or **Either (or)**. **Second** must be linked.
Live line: `Yes`.

### Hold

Takes yes or no, gives yes once its input said yes for **Yes after** and no once it said no for **No after** (each 0 to
3,600 s, default 5 s). Live line: `Yes` or `Yes in 3 s`. Example: a crowd that stays at least a minute, not a group that
walks past.

### Throttle

Takes crossings or pulses and passes at most one per **At most one per** (1 to 3,600 s, default 60 s); the others are
dropped. Live line: `1 passed · 4 held back`.

### Device event

No input, gives yes while an event of the event rules is on, such as an input port or a device trigger.

<Image src={eventType} alt="The Choose event dialog: a search and the events in folders, Door open selected" class="screen fit" />

**Event** opens **Choose event**. Events of Vision Center itself cannot be chosen. Live line: `Yes` or `No`. Example: count
only while the door contact says open.

## Time

Timers and time windows use the server's local time, with daylight saving.

### Timer

No input, gives a pulse. Works only while **Watching**.

| Setting | Values |
|---|---|
| **Every** | **Few minutes**, **Hour**, **Day** (default) or **Week** |
| **Minutes** | For **Few minutes**: 1 to 59, default 15. 15 pulses at :00, :15, :30 and :45 |
| **At** | For **Day** and **Week**, default 00:00 |
| **Day** | For **Week**, default Monday |

The pulse comes with the first picture at or after its time. Times missed while the stream was down are not repeated.
Live line: `Next 00:00`, weekly `Next Tue 06:30`.

Link a Timer to **Reset** of a Count, **Send now** of an Event or a Throttle: click the node, then the **+** left of its
input, or drag from the Timer's output. One Timer can do both: the report carries the
values before the reset.

### Time window

No input, gives yes between **From** and **To** (default 08:00 to 18:00) on the chosen **Days** (none: every day). A
window over midnight belongs to the day it starts; **From** equal to **To** is the whole day. Live line: `Yes until 18:00`
or `No until 08:00`.

Example: link it to **Only while** of an Event to send only during opening hours.

## Output

### Count

Takes objects or crossings, gives a number.

| Input | Value |
|---|---|
| Objects | How many are there now |
| Crossings | In and Out since the last reset. The value is In, or Out for a line that counts Out only. Works only while **Watching** |

It starts at 0 by a pulse into **Reset**, by the rule action [Reset counter](../events/#action-reset-counter) and when
the server restarts. With **Only while** linked it counts only while that says yes and keeps its value meanwhile. Live
line: `14`.

### Statistics

Takes a number, gives its **Highest** (default), **Lowest**, **Average** or **Sum** since a pulse into **Reset** or the
start. Live line: `Highest 14`. Example: the busiest moment of the day, reset at midnight.

### Event

Takes objects, crossings, a number or yes or no, and sends an event to the event rules. Its name is the event's name.
What it sends follows its input: see [Events and rules](../events/).

| Setting | Values |
|---|---|
| **Minimum objects** | Objects only: 1 to 300, default 1 |
| **At least** | Objects and yes or no: 0 to 3,600 s, default 1 s. On only once it held that long |
| **Off after** | Objects and yes or no: 0 to 3,600 s, default 2 s |

**Send now** sends a report on each pulse; **Only while** sends only while it says yes. Live line: `On`, `Off` or
`Fired 3 s ago`.
