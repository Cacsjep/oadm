OADM has two parts:

- **Server**: runs as a service, talks to the devices, keeps the device list, passwords and tasks.
- **Client**: the app you work in. It connects to a server on the same computer or elsewhere.

One server manages up to 30,000 devices.

Download the installer for your system from the [latest release](https://github.com/Cacsjep/oadm/releases/latest).
Every installer offers **Server and client** (default) or **Client only**, for a computer that connects to a server
elsewhere. Uninstalling keeps the data folder (devices, credentials, settings, PKI).

<Aside>
The installers are not signed yet. Check a download against `SHA256SUMS.txt` of the release.
</Aside>

<Tabs syncKey="os">
<TabItem label="Windows">

<Steps>

1. Download `OADM-<version>-win-x64.msi` and double-click it.
2. Choose **Server and client** or **Client only**.
3. Finish. With the server, the Windows service **OADM Server** starts now and on every boot.

</Steps>

- Client: Start menu > **OADM**.
- Data folder: `%ProgramData%\OADM`.
- Uninstall: Settings > Apps > OADM.
- Silent install of the client only: `msiexec /i OADM-<version>-win-x64.msi ADDLOCAL=Client /qn`.

</TabItem>
<TabItem label="Linux">

Debian and Ubuntu (also Raspberry Pi OS), x64 (`amd64`) or ARM64 (`arm64`, e.g. Raspberry Pi 4 and 5). Download the
`.deb` files of your computer's type and install them:

```sh
sudo apt install ./oadm-server_*.deb ./oadm-client_*.deb   # server and client
sudo apt install ./oadm-server_*.deb                       # server only
sudo apt install ./oadm-client_*.deb                       # client only
```

- Server: systemd service `oadm-server` (`sudo systemctl status oadm-server`).
- Client: app menu > **OADM**, or `oadm-client`.
- Data folder: `/var/lib/oadm`.
- Uninstall: `sudo apt remove oadm-server oadm-client`.

<Aside title="Video on the graphics card">
The client decodes video on the graphics card when it can. On Linux it needs the video driver of the graphics
card; without it the processor decodes and an orange warning icon shows over the video. Install the driver:

```sh
sudo apt install intel-media-va-driver   # Intel graphics (older Intel: i965-va-driver)
sudo apt install mesa-va-drivers         # AMD graphics
```

NVIDIA graphics cards use the NVIDIA driver. Windows and macOS need nothing extra.
</Aside>

<Aside>
The notice "Download is performed unsandboxed as root ... couldn't be accessed by user '_apt'" is harmless: apt cannot
read your private home folder and reads the file as root instead. To avoid it, install from `/tmp`.
</Aside>

</TabItem>
<TabItem label="macOS">

Intel Macs (x64).

<Steps>

1. Download `OADM-<version>-osx-x64.pkg`.
2. The package is not signed yet: right-click it, choose **Open** and confirm.
3. For the client only, click **Customize** and clear **OADM server**.

</Steps>

- Server: background service `com.oadm.server`.
- Client: **Applications > OADM**.
- Data folder: `/Library/Application Support/OADM`.
- Uninstall: `sudo /Applications/OADM.app/Contents/Resources/uninstall-oadm.sh`.

</TabItem>
</Tabs>

## Without installing

Every release also has `OADM-Server-<version>-<system>.zip` and `OADM-Client-<version>-<system>.zip`: the server and
the client to run from a folder, without a service, for a test or for plugin development. Unpack and start
`Oadm.Server` and `Oadm.Client`. The server then keeps its data in your user's folder (`%LOCALAPPDATA%\Oadm`,
`~/.local/share/Oadm`, `~/Library/Application Support/Oadm`) and stops when you close it.
