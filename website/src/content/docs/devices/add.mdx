Adding devices is one page, no wizard. OADM logs in to every device it finds with the passwords on your
**Credentials** page, so most devices are ready to add right away.

<Image src={scan} alt="Found devices with their login result" class="screen" />

## Ways to find devices

Click **Add** on the Devices page and choose:

- **Discovery**: finds the Axis devices on the local network. Runs for 30 seconds (change it in Settings).
- **Network range**: enter From and To, press **Scan**. Several ranges add to the same list.
- **Add manually**: an IP address or host name, optionally with port and `https://`. Press **Find**.
- **Import from file**: a CSV file (for example an export from OADM) or a text file with one address per line.
- **Import from ADM**: the device export of AXIS Device Manager.

**Stop** ends a running search; the devices found stay in the list. **Scan again** searches once more.
Devices OADM already manages are not listed.

One server manages up to 30,000 devices. An add that would go over it is refused whole: uncheck devices, or remove
devices you no longer need first.

**Use DNS names instead of IP addresses** (Discovery and Network range) lists and adds the devices by their DNS name.
Devices without a DNS name are added by IP address. OADM keeps the address a device was added with.

## Login results

| Result | What to do |
|---|---|
| Authenticated (user) | Ready. The row is checked. |
| Login failed | Click the row or **Log in**, enter user name and password, **Retry**. A password that works is tried on the other failed devices too. |
| Password not set | Factory default. **Set password** sets the first `root` password when you add the device. **Use for all factory-default devices** applies it to every one. |
| Unreachable | The device does not answer, or did not identify itself as an Axis device. No password was sent to it. |

<Steps>

1. Check the devices you want. **Select all authenticated** checks every ready device.
2. Click **Add 3 devices** in the footer. The page closes and the devices appear in the list.

</Steps>

## Import from a file

<Image src={importFile} alt="Import from file with one row per line" class="screen" />

**Import from file** first shows the columns and an example; **Choose file** opens the file dialog.

- Columns: **Address** (or IP address, IP, Host name), optional **User name**, **Password** and **Tags**. Other columns
  are ignored. Comma or semicolon.
- A password without a user name is for `root`. Logins in the file are tried first and are never saved.
- Up to 30,000 addresses per file. A line with a problem shows **Not added** and the reason in its row.
- **Keep devices that do not answer and add them when they come online** (checked by default): on **Add**, OADM keeps
  the addresses that did not answer and tries them again every 15 minutes (Settings, "Try waiting devices every"). Each
  device is added once it answers, with the login and tags of its line. The Devices page shows how many are waiting;
  click it to see them, try them now, export or remove them. A device that answers but rejects every password waits until
  you click **Try now**.
- Tags in the file are given to the devices you add. Several tags in one cell are separated with `;`.

Example:

```csv title="devices.csv"
Address,User name,Password,Tags
10.0.0.48,root,MyPassword1,Building A
10.0.0.49,,,Building A; PTZ
camera-lobby.example.com,operator,Secret-2026,Lobby
https://10.0.0.60:8443,,,
```

Lines without a login use the credential list. The simplest file is one address per line, without a header:

```text title="devices.txt"
10.0.0.48
10.0.0.49
camera-lobby.example.com
```

<Aside type="tip">
OADM only sends a password after the device answered like an Axis device, and tries HTTPS first. Passwords of
devices you already manage are never tried on new devices.
</Aside>

## Import from AXIS Device Manager

In AXIS Device Manager, export the devices to a file (a `.json` file). In OADM, choose **Add** > **Import from ADM** and
that file. The devices appear on the add page like an import from a file.

- **Addresses**: with their ports. A device is only added when it answers with the MAC address of the export; another
  device at that address shows **Not added** and gets no password.
- **Logins**: tried first and never saved. Devices without a login use the credential list.
- **Tags**: given to the devices you add. Tags OADM does not have yet are created.
- Model, firmware and everything else OADM reads from the devices.

OADM is one server. Devices it cannot reach show **Not found**, for example cameras another ADM server manages. When the
export comes from several ADM servers, OADM asks before the import.
