**Applications (ACAP)** shows the applications on a device and installs or controls them on every selected device. It
is in the context menu under **Applications**.

<Image src={shot} alt="The Applications dialog with the installed applications and the package preview" class="screen" />

## Install or upgrade

<Steps>

1. Select the devices, right-click and choose **Applications** > **Applications (ACAP)**.
2. Click **Install or upgrade** and choose the `.eap` file.
3. The device table shows per device in **Result** whether it is an install, an upgrade, a reinstall or a downgrade,
   and any problem.
   The preview reads up to 25 devices. Other rows say "Checked at install".
4. Optional: click **Add license keys** and choose the license key files (see below). Each device gets its own key right
   after the application is installed.
5. Turn on **Start after install** if the application should run right away. Turn on **Allow downgrade** to install an
   older version.
6. Click **Install**.

</Steps>

## License keys

The **License** column shows the license of each application: **Not required** for applications that need none,
**Missing** when a key is needed. An Axis license key file belongs to one device and one application. You get the files from axis.com for your license
code and the devices' serial numbers (the MAC address).

<Steps>

1. Select the devices, open **Applications (ACAP)** and select the application.
2. Click **Install license** and choose the key files. Choose many at once, or a ZIP file with all of them.
3. OADM gives every device the key with its MAC address. The table shows per device **Key found**, **No key**, **Key
   expired** or **Other application**.
4. Click **Install license**.

</Steps>

<Image src={licenseShot} alt="The license card with the key of every selected device" class="screen" />

A device without a key ends with a warning and nothing is sent to it. A key for another application or an expired key
is not sent. Afterwards OADM reads the license again; the **License** column shows it.

<Aside>
Activating a license automatically with a license code is done on the device's own **Apps** page (in **Web View** or a
browser): the browser asks Axis online for the key. OADM installs key files.
</Aside>

## Start, stop or remove

**Installed applications** lists the applications of the first selected device. With several devices, choose the
device to show. Select an application and click **Start**, **Stop** or **Remove**. The action runs on every selected
device. **Remove** asks for confirmation below the list: **Keep** or **Remove**.

A device that already is in the requested state is left alone. A device without the application ends with a warning.

## What OADM checks first

Before anything is uploaded, OADM reads the package and the device and refuses (Nothing was changed) when:

- the package is not a valid `.eap` file,
- the package is built for another processor type,
- the device's AXIS OS is outside the versions the package supports,
- the package runs as root and the device has AXIS OS 12 or later,
- the package is older than the installed version and **Allow downgrade** is off,
- the application is part of AXIS OS (bundled), for **Remove**.

The dialog warns when the device accepts only signed applications or when the vendor differs from the installed one.
The device checks the signature itself.

## Steps

- Install: Check compatibility, Read package, Read device info, Read SDK version, Read unsigned application setting,
  Read installed applications, Check package, Upload package, Verify installation, and with **Start after install**
  Start application and Verify application state. With license keys: Check license key, Install license key and Verify
  license, before the start.
- Install license: Check compatibility, Read installed applications, Check license key, Install license key, Verify
  license.
- Remove: Check compatibility, Read installed applications, Remove application, Verify removal.
- Start, stop: Check compatibility, Read installed applications, Start application (or Stop application), Verify
  application state.

<Aside>
AXIS OS 13 accepts only signed applications.
</Aside>
